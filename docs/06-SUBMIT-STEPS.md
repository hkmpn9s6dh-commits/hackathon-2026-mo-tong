# 06 — 提交照抄单（用户照着点就行）

> 每一步写清「去哪儿、点哪个、贴什么」。做完在任何一栏回我一句进度即可。
> 全部做完预计 35–45 分钟（不含等待创空间构建）。

## 第 0 步：魔搭账号（约 3 分钟）

1. 打开 https://www.modelscope.cn/ ，右上角「登录 / 注册」。
2. 用手机号登录（大陆可用）。
3. 右上角头像 → 个人中心 → **实名认证**（创空间公开发布需要）。

> 已经实名过就跳过。

## 第 1 步：建创空间（约 5 分钟）

1. 打开 https://www.modelscope.cn/studios → 右上角「**创建创空间**」。
2. 填写：

| 栏位 | 填什么 |
|---|---|
| 所属账号或组织 | 你的个人账号 |
| 空间名称 | `mo-tong`（英文小写） |
| 显示名称 | `墨童 · 一个会学你的小妖怪` |
| 简介 | 复制 `05-SUBMISSION.md` §2 那一句 |
| 可见性 | **公开** |
| 许可协议 | MIT |

3. 点「创建」。

## 第 2 步：上传网页（约 10 分钟）

**方式 A（推荐，最稳）：让我代推**

1. 打开 https://www.modelscope.cn/my/myaccesstoken ，新建一个 token（只读+写），复制。
2. 把 token 发我（这会把 token 写进本机 git remote；用完可以立刻在同一个页面删除）。
3. 我把 `dist/` 直接推到 `https://www.modelscope.cn/studios/<你的用户名>/mo-tong`。

**方式 B：自己在网页上传**

1. 本机跑 `npm ci && npm run build`（或直接用我给你的 `dist/` 压缩包）。
2. 进创空间 → 文件页 → 上传：把 `dist/` **里面的内容**（`index.html` 和 `assets/` 文件夹）上传到**仓库根目录**，不要再套一层 `dist/`。
3. 进「部署设置」→ SDK 类型选 **Static** → 保存。

> 静态空间的硬要求：根目录必须有 `index.html`；如果有 `dist/index.html` 就打不开。

## 第 3 步：冒烟（约 3 分钟）

1. 等状态变成「**运行中**」。
2. 打开 `https://modelscope.cn/studios/<你的用户名>/mo-tong`。
3. 检查三件事：标题页出来了吗；点「落笔」能画吗；画完一笔墨童会走吗。
4. 有任何一项不对，把地址发我，我用无头浏览器跑一遍 `node scripts/e2e.mjs` 对着线上地址定位。

## 第 4 步：报名（截止 **12-01 12:00**，建议 11-16 前做完）

1. 打开小红书，发一条笔记：正文复制 `05-SUBMISSION.md` §6，配图用 `submission/cover-1500x1000.png` 与 `proof/shots/02-drawing.png`。
2. 确认话题与 @ 都在（`#AI无限开发者创作大赛` `#AI造游戏` `#盛趣游戏` `#赞奇科技XSUPERZONE` `#华硕AI智能体电脑`，@魔搭ModelScope社区 @Qoder）。
3. 记下笔记链接。
4. 回活动页 https://www.modelscope.cn/events/394/ → 「立即报名」→ 贴笔记链接 → 提交。
