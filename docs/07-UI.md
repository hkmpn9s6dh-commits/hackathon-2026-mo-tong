# 07 — UI：《墨童》

> 闸 A / 闸 D 的文档。§1–4 在任何界面动笔之前写；§5 之后只在实测之后补。

## 1. 风格预设：*one sheet, one ink*

一整页宣纸，只有墨、朱砂、印泥三种颜色。没有面板、没有卡片墙、没有图标按钮——界面要么是纸上的字，要么是画里的东西。

| Token | 值 | 用途 |
|---|---|---|
| `--night` | `#100e0c` | 纸外的桌面（让纸浮起来） |
| `--paper` | `#f4eddd` | 纸基色 |
| `--paper-deep` | `#e6dcc6` | 纸的暗部、卡片底 |
| `--ink` | `#171310` | 墨、正文 |
| `--ink-soft` | `rgba(23,19,15,.66)` | 次要文字（实测偏淡，正文提到 .8） |
| `--cinnabar` | `#b8372a` | 朱砂：点、印、唯一的强调色 |
| `--cinnabar-deep` | `#8a2317` | 朱砂的暗部、悬停 |
| `--gold` | `#b3903f` | 金：只在「落印」的一瞬出现 |

- **字体**：随包带 **霞鹜文楷 LXGW WenKai**（SIL OFL 1.1），`src/fonts/` 里只有用到的 unicode-range 子集（19 个文件，约 1.1MB，浏览器实际只下载当屏的一两个）。标题、正文、数字全部用它；兜底是 serif，**不允许落到 sans**。
  - 为什么不用系统字体：Windows 有楷体/宋体，macOS 只有 STKaiti/Songti SC，Android 基本没有；一旦落到 sans，整页就成了「设置面板」。2026-11-13 用户指出的「字体出戏」正是侧栏与结算卡片上的小字。
  - 为什么不外链：评审期不能靠网络，也不能假设 Google Fonts 可达。
- **字号只有六级**：12 / 13 / 15 / 16 / 21 / 32，外加标题 128。正文不小于 15（中文比拉丁字需要更大）。
- **规矩**：不用圆角卡片、不用阴影堆叠、不用渐变按钮（唯一例外是印章按钮的纸感渐变）；朱砂一屏最多三处（朱砂点、落款印、主按钮）。
- **动效**：笔触生长用 60fps 的折线推进；朱砂收走溅 18 粒；（`prefers-reduced-motion` 时粒子减半、晃动停止）。

## 2. 尺子 —— 什么算好

| 参考 | 学哪一点 |
|---|---|
| 《绘真·妙笔千山》（网易） | 整屏就是一页古画：界面不能压住画，字要像题跋而不是 UI。 |
| 《大神 Okami》（Clover） | 笔是唯一的输入：一笔既是操作也是画面，笔触本身要有生命。 |
| 《Gris》（Nomada） | 极简关卡 + 颜色作为叙事：一屏只讲一件事，留白是设计不是空缺。 |
| 《Monument Valley》（ustwo） | 视觉秩序：所有元素都服从同一种几何，绝不出现两种质感打架。 |
| 《Alto's Odyssey》 | 单手可玩、节奏平顺：一条连续的动线，失败也不打断呼吸。 |
| 《Sky 光遇》 | 拖尾与风：让「走路」这件事本身好看，玩家会为了看它多走两遍。 |
| 魔搭创空间（宿主） | 宿主是 iframe 里的一个页面：不能假设全屏、不能假设有声音、首屏必须自己站得住。 |

## 3. 一个记忆点

**墨影走的是你画的路，学的是你偷的懒。**
屏幕上只留一个画面：你歪歪扭扭的那一笔，被一个灰墨小人一模一样地走了一遍，还顺手抢走了你想要的朱砂。其余一切（HUD、结算数字）都要安静到不抢这句话。

## 4. 主屏规格

- **画布**：逻辑 1200×750（16:10），`DPR ≤ 2`，按 contain 缩放居中；纸面四周留 8px 的不规则毛边（`paperPath`），纸外是 `--night`。
- **棋盘**：`x 78–992, y 86–674`；右侧 `x 1012–1174` 是题跋栏（习性面板 + 落款印），用一条 1px 的 `rgba(23,19,15,.09)` 细线分开。
- **朱砂点**：半径 21，程序化不规则轮廓 + 12% 的外渗环 + 内部颗粒；未收集时轻微呼吸（±3%）。
- **墨渍**：半径 30–48，多瓣融合的墨团，整张精灵做 1.6px 的模糊，读作「洇进纸里」而不是「黑色圆点」。
- **印**：边长 88 的朱砂方印，白色「墨」字，带侵蚀孔洞，轻微 -3.5° 旋转；作为终点，只在可画时呼吸。
- **笔触**：五道叠出来的——纸纤维的洇（2.1–3×宽、5–10% 透明）、湿肩（1.28×、22%）、实心笔身（1×、95%）、聚墨的深边（0.9px 描边）、干笔飞白与颗粒。
- **墨童**：水滴形身体 + 两道白缝眼睛 + 一笔甩尾 + 腮红；呼吸 3.4Hz，走路压扁拉伸，身后留墨点。
- **习性面板**：右侧题跋栏，**竖排**（`writing-mode: vertical-rl`），从右到左四列：`墨影学到的` → `绕远`+三点墨度+`走直线` → `贴边`… → `摆幅`…。字号 15–17px，不再用 11–13px 的灰色横排小字。
- **HUD**：全部按 1200×750 的逻辑单位排版，整体随纸缩放（`transform: scale`），永不与纸错位。
  - 左上：`第X关`（15px 朱砂）+ 关名（32px 文楷）。
  - 右上：墨量条（132×5）。
  - 右下：`看它画` / `重画` / `声`，15px 楷体下划线按钮。
  - 左下：一行提示，16px 楷体。
- **结算**：一张毛边纸片（`clip-path` 24 点抖动），`收笔落印` 30px，四个数字用 1px 竖细线分隔，右下角一枚 38px 的小印。
- **收卷**：760×1080 的册页，两列排出你完成的每一关，右侧竖排落款与日期，右下落印。

## 5. 记录在案的取舍

1. **正文提到 `rgba(23,19,15,.8)`**：设计 token 里 `--ink-soft` 是 .66，实测在宣纸底上偏淡（截图对比度约 3.9:1），正文与提示改用 .8（约 5.6:1）；`.66` 只留给「被抢走」「脚注」这类次要信息。
2. **一屏三处朱砂**：朱砂点（多为 3–7 颗）、落款小印、主按钮。朱砂点是游戏对象不是装饰，落款印是身份，主按钮是全屏唯一可点的大目标，因此不算超配。
3. **关卡 1 只有 3 颗朱砂、2 团墨渍**：教学关故意留白；第 4 关起密度翻倍，不为了「看起来满」在第一屏堆元素。
4. **字体不外链**：优先 `KaiTi`，macOS 回落 `STKaiti`，都没有时回落系统衬线。字形差异在可接受范围，胜过评审期字体加载失败。
