# 01 — SPEC：《墨童》

> 先写演示脚本，再写能判定的验收条件。过闸 A 之后范围只减不增。

## 1. 一句话

在宣纸上画一笔，墨童照着走；你走得越多，它越像你——最后一局，它用你的习惯跟你抢朱砂。

## 2. 演示脚本（约 100 秒，也是视频的分镜）

| 时间 | 画面 | 旁白/字幕要说清的 |
|---|---|---|
| 0–8s | 标题页：墨童两个字、右半页一笔自己画出来，小墨童跟着走 | 这是「一笔画」：一条线，从起笔到落印 |
| 8–26s | 第一关：画一笔，穿过三颗朱砂，收在「墨」印上；墨童沿墨迹走，朱砂逐颗炸开 | 规则一句话：一笔连起所有朱砂，收笔落印；墨渍碰不得 |
| 26–46s | 第二、三关：墨渍变多，需要回撤笔路绕过去；失败一次（收笔没落印）再成功 | 笔路可以回撤；墨量有限 |
| 46–66s | 第四关：**墨影先走**。它的路线和你上一关的笔路同款（同样的兜圈、同样的贴边），抢走两颗朱砂 | 它学的就是你：绕远、贴边、贪近、摆幅 |
| 66–82s | 侧栏「墨影学到的」三条习性条随每关变化；第六关专门画得「逆着来」，看它跟着变 | AI 是活的：习性来自你的笔画，不是写死的脚本 |
| 82–100s | 终局对影 → 收卷：册页上是你七关的笔迹，落款与印章 | 你的每一笔都留在画里，可下载 |

## 3. 玩法定义（可判定的口径）

- **一笔**：从墨童身上起笔，按住拖动，松开结束；笔路长度受「墨量」限制（`level.inkBudget`）。
- **阻挡**：笔尖不能进入墨渍（圆）；撞上就停住，笔路不前进。
- **收集**：笔路与朱砂的最近距离 ≤ `dot.r + 0.7 × 笔宽` 记为经过；墨童走过去时逐颗收走。
- **完成**：本关未被墨影抢走的朱砂全部经过，且收笔点落在印内（≤ `goal.r`），且用墨 ≤ 上限。
- **墨影**：第 4 关起，先于玩家行动。走法 = 本关基准路线 + 按玩家习性做的四种形变（绕远加鼓包、贴边向最近墨渍靠、贪近改访问顺序、摆幅加正弦抖动），最多抢走 40% 的朱砂。
- **习性**：每完成一关，从这一笔里估五个参数（绕远 / 贴边 / 贪近 / 摆幅 / 行笔），指数平滑进人物模型；侧栏显示三条。

## 4. 验收条件

| # | 条件 | 怎么验 |
|---|---|---|
| AC-1 | 七个关卡的基准路线都能通关（经过全部朱砂、落印、不超墨量） | `vitest`：`keeps every reference route solvable, inside the ink budget` |
| AC-2 | 墨渍真的挡笔（穿过墨渍的位移被判阻挡），空白处不挡 | `vitest`：`blocks a move that would drag the brush through a blot` |
| AC-3 | 墨渍不会压在基准路线上（关卡的解一定存在） | `vitest`：`never puts a blot on the reference route` |
| AC-4 | 关卡由种子决定，同一 seed 每次一样 | `vitest`：`builds the same level from the same seed` |
| AC-5 | 少一颗朱砂 / 没收在印上 / 超墨量，都不算完成 | `vitest`：`does not count a stroke that…` 三条 |
| AC-6 | 直线笔被判为「不绕远、不抖」；抖动笔被判为「绕远、抖」 | `vitest`：`reads a straight, steady stroke…` / `reads a shaky…` |
| AC-7 | 墨影的走法随习性变长（绕远高 → 路更长），且最多抢 40% | `vitest`：`makes a wandering shadow walk a longer route`、`never lets the shadow take more than 40 %` |
| AC-8 | 生产构建通过（类型 + 打包），产物用相对路径，可放进任意子目录 | `bash scripts/verify.sh`（`npm run build` + 相对路径检查） |
| AC-9 | 浏览器里能真的从第一关玩到收卷，收卷能生成可下载的画 | `node scripts/e2e.mjs`：`finale composes a scroll` |
| AC-10 | 在线版可玩（GitHub Pages），且无 console 错误 | `node scripts/e2e.mjs`：`no console errors`（对线上地址跑一次） |
| AC-11 | 414px 宽的手机上不横向溢出、按钮可点 | `node scripts/e2e.mjs`：`no horizontal overflow at 414px` |
| AC-12 | 魔搭创空间静态托管能跑：根目录 `index.html` + `ms_deploy.json` 的 `sdk_type: static` | `verify.sh` 两条卫生检查 + 创空间实测（用户部署后冒烟） |
| AC-13 | 仓库不含密钥 | `verify.sh` 的 `no api keys committed` |

## 5. 不做（范围冻结）

- 不做账号、排行榜、后端、云存档。
- 不做关卡编辑器。
- 不接任何云端大模型 API（本机不可达，且会破坏「点开就能玩」）。
- 不做中英双语切换：正文中文，关键名词给一行英文小注。

## 6. 黄金路径

标题 →（落笔）→ 第一关（一笔三朱砂）→ 结算 → 第二关 …… → 第七关（对影）→ 收卷 → 存画。
每一步都能在半分钟内被评委复现；任何一关失败都可以「重画」，不扣分。
