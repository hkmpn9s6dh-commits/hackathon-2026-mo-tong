## 1. 作品名

「**墨童**（Mo Tong）——一个会学你的小妖怪」

## 2. 一句话（创空间简介 / 列表页用，≤60 字）

「在宣纸上画一笔，墨童照着走；你走得越多，它越像你——最后一局，它用你的习惯跟你抢朱砂。」

## 3. 创意说明（提交页「作品介绍」）

「《墨童》是一款一笔画小游戏：你在宣纸上按住拖动，画出一条墨线，小墨童就沿着这条线走，沿途收走朱砂，最后要收笔落在「墨」印上。墨渍碰不得，笔路可以回撤，每关墨量有限。

它和常见一笔画不同的地方是：**从第四关起，会出现一个墨影，它先走一步，而且走法是从你的笔画里学来的**。你爱绕远，它就绕一个鼓包；你爱贴着墨渍走，它就贴着边走；你爱先拿最近的朱砂，它就按最近优先去抢。它抢走的朱砂，你这一关就拿不到了。

七关之后收卷：这一局你画下的每一笔都在一页册页上，可以存下来。

整页宣纸、每一笔墨迹、每一颗朱砂、每一枚印章，都是 Canvas 现场画出来的——仓库里没有一张图片、没有一个音频文件。」

## 4. AI 怎么用的（这一栏是评审重点）

「墨影的行为不是写死的脚本，是一条可复现的学习管线：

1. **取样**：每完成一关，从玩家这一笔里估五个参数——绕远（笔路长度 ÷ 近似最优巡游长度）、贴边（到最近墨渍的平均余量）、贪近（取朱砂的顺序与「最近优先」的一致度）、摆幅（笔路相对自身平滑线的偏差）、行笔（长度 ÷ 落笔时长）。
2. **建模**：五个参数用指数平滑进人物模型（`src/core/learn.ts`：`extractStyle` / `blendStyle`），第一关直接定义，之后每关按 55% 的权重更新。
3. **生成**：`planShadow` 把模型变形成一条具体路线——绕远加一个高斯鼓包、贴边把路线往最近墨渍推（但不推进去）、贪近改成最近优先的访问顺序、摆幅加正弦抖动。
4. **约束**：墨影最多抢走 40% 的朱砂，保证关卡一定可通（这是设计上的保护，写死在代码和测试里）。

五个参数、四种形变、抢点上限，全部有单元测试；同一关同一习性，墨影的路线完全一致（`buildLevel` 与 `planShadow` 都用固定种子）。」

## 5. 怎么玩（操作说明）

- 按住**墨童**拖动落笔，松开结束。
- 一笔要**穿过所有朱砂**，并且**收笔落在「墨」印里**。
- 笔尖碰不得**墨渍**；撞上就停住，可以往回拉再绕。
- 右上角是剩下的墨；用完这一笔就断了。
- 右下角「看它画」可以让它自己走一遍（不会记录你的习性）。
